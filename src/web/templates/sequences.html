How sequences work
  1. Enqueue a CSV — every lead with an email gets enrolled in a 7-step nurture (one per row). Claude drafts all 7 emails up-front using the lead's business + niche so each is hyper-personalized.
  2. Background scheduler wakes every 60 seconds and sends any step whose scheduled_for time has elapsed. You don't have to do anything once enrolled.
  3. Cadence (28 days): day 0 cold → day 3 bump → day 7 FOMO → day 11 Loom → day 16 math → day 21 quirky → day 28 pizza breakup.
  4. Replies pause the sequence automatically via the Gmail scan + Resend webhook. No more emails go to anyone who's already engaged.
  5. "Send due steps now" manually triggers a tick if you don't want to wait the 60 seconds for the next scheduled run.
